# ATM Cash Replenishment Optimization

A machine learning-based desktop application that predicts ATM cash replenishment requirements using historical transaction data.

## Features
- Cash prediction using Random Forest
- Modern CustomTkinter UI
- Analytics Dashboard
- Prediction History
- SQLite Database
- Interactive Graphs

## Technologies Used
- Python
- CustomTkinter
- Scikit-learn
- Pandas
- Matplotlib
- SQLite

## Note
The trained model file (`atm_model.pkl`) is excluded from GitHub because it exceeds GitHub's file size limit.
